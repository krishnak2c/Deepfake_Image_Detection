# 🛡️ Deepfake Image Detection

[![Hugging Face Space](https://img.shields.io/badge/%F0%9F%A4%97%20Hugging%20Face-Space-blue)](https://huggingface.co/spaces/krishnak2c/deepfake-image-detection)
[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![TensorFlow 2.15+](https://img.shields.io/badge/TensorFlow-2.15+-orange.svg)](https://tensorflow.org/)

A state-of-the-art deep learning solution for identifying AI-generated facial images. This project utilizes a fine-tuned **EfficientNetB0** architecture to distinguish between authentic human faces and those generated by sophisticated GANs (Generative Adversarial Networks).

---

## 🌟 Key Features

*   **⚡ High-Performance Inference:** Leverages `EfficientNetB0` pre-trained on ImageNet for superior feature extraction.
*   **🎨 Intuitive UI:** Modern web interface built with **Streamlit** for seamless image uploads and instant analysis.
*   **🧠 Advanced Training:** Implements a two-phase training strategy (Feature Extraction + Fine-Tuning) for maximum accuracy.
*   **📊 Performance Analytics:** Automatically generates training history visualizations (accuracy/loss plots).
*   **🛠️ Robust Pipeline:** Optimized `tf.data` input pipeline with mixed-precision training for speed and efficiency.

## 🚀 Getting Started

### 1. Prerequisites
*   Python 3.9 or higher
*   Git

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/Deepfake_Image_Detection.git
cd Deepfake_Image_Detection

# Create a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Usage

#### **Run the Web App**
```bash
streamlit run app.py
```
Access the application at `http://localhost:8501`.

#### **Train from Scratch**
1.  Organize your dataset in `dataset/train` and `dataset/valid` with `FAKE/` and `REAL/` subdirectories.
2.  Configure parameters in `config.py`.
3.  Execute: `python train.py`

---

## 🧠 Model Architecture & Dataset

*   **Base Model:** `EfficientNetB0` (Frozen during Phase 1, Unfrozen during Phase 2).
*   **Top Layers:** GlobalAveragePooling2D → Dense(512, ReLU) → Dropout(0.5) → BatchNormalization → Dense(256, ReLU) → Dropout(0.3) → Dense(1, Sigmoid).
*   **Dataset:** Trained on ~140,000 images.
    *   **70,000 REAL:** Sourced from Flickr-Faces-HQ (FFHQ).
    *   **70,000 FAKE:** Generated using StyleGAN.
